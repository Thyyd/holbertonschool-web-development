# Projet HTML Advanced

Projet durant lequel nous avons pas à pas rédigé un code HTML à partir d'un wireframe (Ici, Figma.)

## Description des étapes réalisées

Nous avons dans un premier temps écrit simplement le code HTML, avec seulement les balises nécessaires, sans CSS pour avoir la structure de la page.

Ensuite, nous les avons mis à jour avec différentes classes et id pour nous permettre de la styliser à l'aide d'un fichier CSS, pour recréer la page web que nous avions avec le wireframe.

## Objectifs

- Apprendre à structurer une page Web avec HTML
- Mettre en pratique la création de sections, titres, paragraphes, listes et liens à partir d'un wireframe.
- Préparer une base pour ajouter des styles CSS plus tard.

## Fonctionnalités

- Header avec Logo et plusieurs liens
- Main contenant : 
  - Partie Principale, que l'on voit directement quand on arrive sur le site
  - Partie Témoignages, avec un témoignage
  - Partie Tutoriels Populaires
  - Partie Free Membership
  - Partie FAQ
- Footer avec informations de contact
