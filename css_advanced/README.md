# Projet CSS Advanced

Projet durant lequel nous avons pas à pas rédigé le code CSS d'un code HTML créé à partir d'un wireframe (Ici, Figma).

## Objectifs

- Apprendre à appliquer des styles CSS aux différentes sections d'une page.
- Mettre en pratique les sélecteurs, propriétés CSS, couleurs, polices et mise en page.
- Respecter le wireframe initial tout en améliorant la lisibilité et l’ergonomie.

## Styles et fonctionnalités ajoutés

- Couleurs et typographie pour améliorer la lisibilité
- Mise en page avec Flexbox
- Header et footer stylisés
- Mise en forme des listes et paragraphes
